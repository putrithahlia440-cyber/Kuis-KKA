Soal 1 — Kondisi Lampu

Buatlah program Python menggunakan if-else untuk menentukan kondisi lampu.

Program meminta pengguna memasukkan kondisi lampu "nyala" atau "mati".

Ketentuannya:

  • Jika lampu = "nyala", tampilkan “Lampu sedang menyala”.
  • Jika selain itu, tampilkan “Lampu sedang mati”.

Tuliskan kode Python lengkap pada kotak berikut.

Soal 2 — Pengumpulan Tugas

Buatlah program Python menggunakan if-else untuk menentukan apakah tugas diterima atau terlambat.

Program meminta pengguna memasukkan jam pengumpulan tugas.

Ketentuannya:

  • Jika jam pengumpulan kurang dari atau sama dengan 15, tampilkan “Tugas diterima”.
  • Jika lebih dari 15, tampilkan “Tugas terlambat”.

Tuliskan kode Python lengkap.

Soal 3 — Jumlah Buku

Buatlah program Python menggunakan if-else untuk menentukan apakah jumlah buku sudah cukup.

Program meminta pengguna memasukkan jumlah buku.

Ketentuannya:

  • Jika jumlah buku 3 atau lebih, tampilkan “Buku sudah cukup”.
  • Jika kurang dari 3, tampilkan “Buku masih kurang”.

Jika nama variabel terdiri dari dua kata, misalnya jumlah buku, gunakan underscore sehingga menjadi jumlah_buku.
