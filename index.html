Kuis IF-ELSE Python

Tuliskan kode Python berdasarkan kasus yang diberikan.

Soal 1 — Kondisi Lampu

Buatlah program Python yang meminta pengguna memasukkan kondisi lampu, yaitu nyala atau mati.

Jika kondisi lampu adalah nyala, tampilkan:

Lampu sedang menyala

Jika kondisi lainnya, tampilkan:

Lampu sedang mati

Nama variabel boleh menggunakan nama sederhana seperti lampu atau nama gabungan seperti periksa_lampu.

Soal 2 — Batas Waktu Pengumpulan

Buatlah program Python yang meminta pengguna memasukkan jam pengumpulan tugas.

Jika jam pengumpulan kurang dari atau sama dengan 15, tampilkan:

Tugas diterima

Jika lebih dari 15, tampilkan:

Tugas terlambat

Nama variabel boleh ditentukan sendiri. Jika terdiri dari beberapa kata, gunakan underscore, misalnya jam_pengumpulan.

Soal 3 — Jumlah Buku

Buatlah program Python yang meminta pengguna memasukkan jumlah buku.

Jika jumlah buku lebih dari atau sama dengan 3, tampilkan:

Buku sudah cukup

Jika kurang dari 3, tampilkan:

Buku masih kurang

Nama variabel boleh ditentukan sendiri. Jika terdiri dari beberapa kata, gunakan underscore, misalnya jumlah_buku.
